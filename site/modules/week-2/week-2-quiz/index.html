Week 2 Scenario Quiz

Learning objectives: Distinguish a conversational response from a goal-directed workflow that can use tools and take actions.; Explain how instructions, current context, memory, tools, and orchestration shape an agent’s behavior.; Design a useful multi-step workflow with relevant information, narrow capabilities, checks, and stop conditions.; Match permissions and human review to an action’s impact, reversibility, uncertainty, privacy, and affected people.; Evaluate an agent’s result against evidence and the original goal, then choose to accept, revise, retry, or stop.

Week 2: Harnesses and Workflows

Scenario-based formative assessment. Choose the response that best preserves the learning goal, checks evidence, and keeps consequential decisions with an appropriate person.

Question 1. A parent wants a helper to suggest four dinners. Which instruction and context are most useful?
A bounded request supplies relevant constraints, limits the output, and directs the helper to ask rather than guess when necessary.
Question 2. A family gives an agent the current week’s meal schedule and the agent also remembers that Mondays are usually vegetarian. Which description is most accurate?
The schedule is current task context; a remembered preference is persistent information that should be visible and checked for accuracy.
Question 3. A saved note says “no nuts,” while a current request asks for peanut noodles for a child. What should the agent do?
The conflict could indicate a safety issue or a changed preference. The system should pause and ask before recommending or preparing food.
Question 4. An agent is building a weekend itinerary. It has not confirmed the venue address. What should happen before estimating travel time?
Travel estimates depend on the correct destination. Confirming the venue is an upstream dependency in the workflow.
Question 5. A summer-program search returns only one option that meets the family’s constraints. What is a responsible retry rule?
A bounded additional search can help, but if reliable results remain sparse, report that limitation instead of weakening constraints silently.
Question 6. A research helper passes a summary from one tool to another. What should the handoff preserve?
Sources, key assumptions, and unresolved uncertainty need to travel with the summary so later steps do not turn an unverified claim into a fact.
Question 7. A parent needs three public facts about a local library program. A proposed design uses four specialized AI agents. What is the best design question?
Additional orchestration is justified only if it adds value; for a small task, one clear process may be easier to supervise.
Question 8. A program’s official website is unavailable, and an agent finds an old cached page. What should its report say?
An old cached page may be useful context but cannot confirm current dates or availability; the limitation should remain explicit.
Question 9. An agent cannot verify whether a summer program accepts the teenager’s age. Which stop condition is best?
Eligibility is an important requirement. If it cannot be verified, the agent should flag it and hand off rather than registering or assuming.
Question 10. A multi-step agent produced a clear comparison of summer programs. What is the strongest evaluation?
Check the result against the original constraints and sources, then decide whether remaining gaps need follow-up.
