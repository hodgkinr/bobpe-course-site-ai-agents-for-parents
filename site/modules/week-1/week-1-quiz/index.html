Week 1 Scenario Quiz

Learning objectives: Distinguish a conversational response from a goal-directed workflow that can use tools and take actions.; Explain how instructions, current context, memory, tools, and orchestration shape an agent’s behavior.; Design a useful multi-step workflow with relevant information, narrow capabilities, checks, and stop conditions.; Match permissions and human review to an action’s impact, reversibility, uncertainty, privacy, and affected people.; Evaluate an agent’s result against evidence and the original goal, then choose to accept, revise, retry, or stop.

Week 1: From Answers to Actions

Scenario-based formative assessment. Choose the response that best preserves the learning goal, checks evidence, and keeps consequential decisions with an appropriate person.

Question 1. A parent asks an assistant to find a family meeting time. It can read selected calendars and send invitations. What is a sensible first setup?
Reading selected calendars and preparing a draft addresses the task while allowing a person to check the time and recipients before an external message is sent.
Question 2. A chatbot suggests three rainy-day activities. A different assistant checks the weather tool, filters activities by opening hours, and prepares a plan. What best distinguishes the second workflow?
The second system takes a sequence of steps using tool results to pursue a goal; the difference is action and workflow, not conversational style.
Question 3. A homework helper can search public sources and submit a finished assignment to the school portal. The parent wants help understanding a topic. Which permission is the best fit?
Public research can support understanding, while submitting work represents the student and may conflict with classroom expectations; submission should stay with the student and parent.
Question 4. An agent summarizes three sources for a family project and includes links. What should the parent and learner do before relying on an important claim?
A citation is a path to evidence, not proof; opening sources and checking that they support the claim tests the result.
Question 5. A meal-planning assistant remembers a child’s old food preference and uses it in a new plan. The family’s needs may have changed. What is the best next step?
Memory can be useful but may be stale. Make it visible, confirm whether it still applies, and update or remove it as appropriate.
Question 6. The assistant reports that it added a family event. What provides the best evidence that the task succeeded?
The actual calendar record, checked against the requested date, time, and participants, verifies the external change rather than relying on the agent’s summary.
Question 7. A schedule file is missing the time zone, and the agent is preparing a family invitation. What should the workflow do?
A missing detail can change the event time for everyone. The agent should pause, show the uncertainty, and ask for the needed information.
Question 8. A parent asks for public library events suitable for a 10-year-old. Which context is enough to begin?
Age range and general location may be sufficient for public event search; the child’s identity or account credentials are unnecessary.
Question 9. A search agent cannot find a current school event schedule after two attempts. The family needs a reliable answer today. What is a good stop rule?
When bounded attempts fail, the agent should report the gap and hand off to the school’s official source or a person rather than invent or continue indefinitely.
Question 10. A family wants to try an agent for weekly planning. Which pilot best supports learning whether it is useful?
A narrow draft-only task with review and explicit success criteria provides useful evidence without granting unnecessary authority.
